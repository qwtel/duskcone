# Duskcone

Duskcone brings Twilight Princess to Meta Quest, based on [Dusklight](https://github.com/TwilitRealm/dusklight). It supports
Quest 2, Quest 3, and Quest 3S.

> [!IMPORTANT]
> **This is an unofficial, independent fork of [Dusklight](https://github.com/TwilitRealm/dusklight).**
> It adds OpenXR support for Meta Quest headsets. It is **not affiliated with,
> endorsed by, or supported by [TwilitRealm](https://github.com/TwilitRealm) or
> the upstream Dusklight project**. Report Duskcone-specific bugs in
> [this repository's issues](https://github.com/qwtel/duskcone/issues), rather than
> upstream; please do not direct port-specific problems to the upstream maintainers.
>
> For desktop builds and upstream development, visit
> **https://github.com/TwilitRealm/dusklight**. This fork is experimental.

This repository currently hosts builds and releases. Source code will be
published here later.

## Downloads

Get the signed Quest APK from [Releases](https://github.com/qwtel/duskcone/releases).
Experimental beta builds are marked as prereleases.

> [!IMPORTANT]
> Duskcone does *not* provide any copyrighted assets. You must provide your own copy of the original game.
